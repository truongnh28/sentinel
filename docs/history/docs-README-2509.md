| Tài liệu | Nội dung |
|---|---|
| [Phuong-phap-luan-trien-khai.md](Phuong-phap-luan-trien-khai.md) | **Tài liệu chính.** Phương pháp luận triển khai đầy đủ: đặt vấn đề, mô hình hình thức, lý thuyết, triển khai theo 11 stage (0–10), nối với SWE-bench, nguồn gốc tham số, kiến trúc, đe doạ tính hợp lệ và câu hỏi phản biện dự kiến |

| [AuditGame-SE_Parameter_Estimation_Report.md](AuditGame-SE_Parameter_Estimation_Report.md) | Báo cáo phương pháp ước lượng tham số: khung bốn phương thức xác lập (đo, neo rồi quét, suy dẫn, khử tham số), kết quả tám đại lượng đã ước lượng, và thủ tục ước lượng cho chín tham số chưa xác lập |
